# Writing cheatsheet

Personal desk reminder. Lossy on purpose. Full reasoning lives in `scientific_writing_map.md`.

## Before you trust yourself

```
title = a sentence someone could disagree with      (the template pulls you back)
every H: one reason for, one against — in the lit review, not bolted on
every number: which level? which denominator?
every concept you introduce: where is it paid off?
one concept, one word — never vary                  (Chinese training pulls you back)
```

```
DESIGN (author):   message → findings → details
PRESENT (reader):  motivation → message → details
Author chronology ≠ reader logic.
```

## Days 1–2 in six questions

```
1. What should the reader leave believing?              → message
2. What findings are necessary to establish it —
   including the ones that qualify or challenge it?     → claims / evidence
3. What does each finding answer?                       → prediction/RQ → hypothesis → central question
4. What does the reader need before seeing that answer? → Context / Need + paper architecture
5. What comparison makes each major claim visible?      → display
6. Only then draft prose.
```

## The tree

```
                 MESSAGE   (so what)
                    |
          ---------------------
          |         |         |
       CLAIM 1   CLAIM 2   CLAIM 3    ≈3 per level
        /  \                 /  \
      info info            info info  (what)
```

Reader sees the whole map: where am I / where going / what options.
Tree, not chain — one weak branch doesn't kill the others.

## Abstract = the map in miniature

Reader uses it to decide whether to keep reading. It must answer, in order:

```
Why?                 Context → Need
What did you do?     Task (we did, past) | Object (paper does, present)
What did you find?   Findings
So what?             Conclusion → Perspectives
```

Before (why needed) · Work (what we did) · After (what we learned, what follows).
Abstract carries all seven; Introduction expands the same moves at paper scale.
Standalone: readable without the paper. Message, not just information.

no after → promissory · no before → out of the blue · no need+conclusion → self-centered

## Evidence chain

```
result → prediction/RQ → hypothesis → central question
```

Orphan result → cut / appendix / other paper.
Read it backwards too: the verb in the claim names the test it needs.

## Skeleton

```
Problem (hook → slant → stakes; show, don't declare)
→ lit/gap → context (why here?) → H/RQ → predictions → methods preview → answer up front
```

Paragraph: topic → development → clincher.
Title = context + finding, not a cute phrase.
Restate the H where you test it. Reader remembers nothing.

## Sentence — two moves and one place

```
UNDERLINE  first 5–6 words of every sentence, read only those
             → subject a character?  (1)     → each start picks up the last end?  (3)
CIRCLE     last 3–4 words of every sentence
             → new, not metadiscourse? (4)   → first sentence's circle = the paragraph? (5)
LOOK       paragraph unfocused → read its last two sentences first; the theme is there
```

nominalization = verb hiding in a noun (comparison → compare); keep it only if it points back (*This pattern…*) or is a term (*layering*)
passive is fine when the reader doesn't need the agent and the subjects stay consistent

## Display

claim → comparison needed → display.

```
Table 1 / Figure 3          NUMBER
<claim sentence>            TITLE     could a reader disagree?  (strict APA: label here,
                                      claim = first line of Note)
headings + body             BODY      labels mean something alone; % beside n
Note. …                     NOTE      = the instrument: level, denominator, sample,
                                      time, encodings, the anomaly, numbers not in the body
ᵃ … / * p < .05             SPECIFIC / PROBABILITY  facts and thresholds, never interpretation

Text:  claim + statistic (Figure 3).   never "Figure 3 shows the distribution…"
```

Standalone test: title + abstract + all notes tell the story alone.
CIs on all bars or none. No screenshots.
→ `figure_table_checklist.md`

## Words that get caught

```
demonstrate / integrate / reconcile / confirm  → which test paid for this?
"most … primarily"                              → one hedge, or the number
crucial / essential / significant (non-stat)    → give the reason instead
evolve                                          → develop
a null stated as an H                           → H0, "fails to reject"
cited verb ≠ what the source did                → find / argue / note?
X was due to Y (both nouns)                     → two clauses, "because" — see what it hides
```

## Revise big → small

```
message → structure → flow → wording → proof
```

Don't polish sentences until message and structure pass.
Sit in the reader's chair for this pass — the tools all sit in the author's.
